# Other calculators and CAS software

CASSim is one way to practise on a CAS calculator. The makers of each calculator also sell their own computer and phone versions, and there is free software that does the same algebra. This page lists them, with a short comparison. Prices and free-plan limits change often, so check the linked page before you buy anything. (Checked November 2026.)

Words used below:

- **Official app**: the calculator maker's own program that looks and works like the handheld.
- **Emulator**: a program that runs the real calculator's own software, which you copy from your own handheld.
- **Same engine**: the algebra system inside the calculator, in a different program.
- **Look-alike**: a different program that understands the same commands or language.

## Computer software for the exam

In VCE Mathematical Methods and Specialist Mathematics, approved schools may let students use approved CAS software on a computer in Examination 2 instead of a handheld. For 2026 the list included Mathematica, Maple and MATLAB, as well as the calculator makers' own programs. Always check the current [VCAA approved technology](https://www.vcaa.vic.edu.au/assessment/vce/authorised-materials-and-equipment) list and your school's rules: the rules change for 2027.

### Mathematica (Wolfram Language)

Official site: [wolfram.com/mathematica](https://www.wolfram.com/mathematica/)

| Option | Type | Cost | Notes |
|---|---|---|---|
| Mathematica | Official, desktop | Paid; many schools have a site licence | The full program. |
| [Wolfram Cloud Basic](https://www.wolframcloud.com/) | Official, browser | Free | Short computations only, and files expire after 60 days. Needs internet. |
| [Wolfram\|Alpha](https://www.wolframalpha.com/) | Official, browser | Free plan and paid plan | Answers questions typed in plain English. Not the same as Mathematica. |
| [Wolfram Engine](https://www.wolfram.com/engine/) | Official, the engine without the notebook | Free for developers | Also comes free on a Raspberry Pi for non-commercial use. |
| [Mathics3](https://mathics.org/) | Look-alike, open source | Free | Understands much of the Mathematica language. Written in Python and built on SymPy. |
| [Woxi](https://github.com/ad-si/Woxi) | Look-alike, open source | Free | New. Written in Rust; runs in a browser; many functions are still missing. |

More look-alikes are listed in this [Mathematica Stack Exchange question](https://mathematica.stackexchange.com/questions/4454/is-there-an-open-source-implementation-of-mathematica-the-language).

## Other free CAS software

These are free and open source. None is approved for the exam, but each is good for checking answers or exploring.

| Program | What it is | Most like | Written in | Language you type | Runs on |
|---|---|---|---|---|---|
| [Maxima](https://maxima.sourceforge.io/) (with [wxMaxima](https://wxmaxima-developers.github.io/wxmaxima/)) | A long-standing CAS with its own language | Maple, in style | Common Lisp | Its own (Algol-like to read, Lisp-like underneath) | Windows, macOS, Linux |
| [Xcas](https://xcas.univ-grenoble-alpes.fr/en.html) | A CAS with graphs, geometry and a spreadsheet | The HP Prime (same engine); has Maple and TI-89 input modes | C++ | Its own, or Maple, MuPAD or TI-89 style | Windows, macOS, Linux, browser |
| [SageMath](https://www.sagemath.org/) | A large system that joins many open-source maths programs, using Python | Mathematica and Maple, in scope | Python and Cython | Python, plus maths notation | Linux, macOS, Windows (via WSL), browser ([CoCalc](https://cocalc.com/)) |
| [SymPy](https://www.sympy.org/) | A CAS library for Python | Mathematica, if you write Python | Python | Python | Anywhere Python runs; [SymPy Live](https://live.sympy.org/) in a browser |
| [Scilab](https://www.scilab.org/) | Numerical computing and simulation, with little algebra | MATLAB, but not code-compatible | C, C++ and Java | Its own, close to MATLAB's | Windows, macOS, Linux |
| [Julia](https://julialang.org/) with [Symbolics.jl](https://symbolics.juliasymbolics.org/) | A fast language for numerical computing; Symbolics.jl adds a CAS | MATLAB, in style (arrays, plotting) | Julia (and C) | Julia | Windows, macOS, Linux |
