# Keys and shortcuts

## On a computer keyboard

| Key | What it does |
|---|---|
| Enter | Calculate the entry |
| Ctrl+Enter | Give the answer as a decimal (same as `approx(...)`) |
| Esc | Cancel a calculation that is running, or close a menu |
| F2 | Open the Menu |
| F4 | Open the Doc menu |
| Up and down arrows | Move through earlier entries and answers |
| Ctrl+/ | Fraction template |
| Ctrl+I | Add a page (choose its type) |
| Ctrl+Alt+I | Add a Problem (choose its first page's type) |
| Ctrl+Left, Ctrl+Right; Alt+Left, Alt+Right | Previous and next page |
| Ctrl+Up | Page sorter |
| Ctrl+L | Variables menu |
| Ctrl+N, Ctrl+O, Ctrl+S | New, open, save document |
| Ctrl+Z, Ctrl+Y | Undo and redo |
| Ctrl+C, Ctrl+X, Ctrl+V | Copy, cut and paste |
| Ctrl+A | Select the whole entry |
| Tab, Shift+Tab | Next, previous field or template slot |
| Shift+Left, Shift+Right | Select part of an entry |
| Ctrl+Shift+Left, Ctrl+Shift+Right | Select by word |
| Shift+Home, Shift+End | Select to the start, end of the entry |
| Ctrl+Space | Insert an underscore |
| Ctrl+= | Insert ≠ |
| Caps Lock | Capital letters |

CASSim takes its own shortcuts before the browser can also use them. This includes Ctrl+N,
Ctrl+O, Ctrl+S, Ctrl+L, Ctrl+G, Ctrl+R, Alt+Left/Right, F1 and Shift+F10. The Mac Command key
is treated as Ctrl when the browser sends it to CASSim. A browser or operating system can still
reserve a shortcut before a web page receives it; use the on-screen controls or Doc menu in that
case. On some keyboard layouts, Ctrl+Alt also acts as AltGr, so Ctrl+Alt+I may conflict with
typing.

### Lists & Spreadsheet

| Key | What it does |
|---|---|
| Ctrl+G | Go to a cell |
| Ctrl+R | Recalculate |
| Page Up, Page Down | Move by a screen of rows |
| Shift+Tab | Select all cells |
| Shift+Up, Shift+Down | Extend the cell selection by a row |
| Alt+Shift+Left, Alt+Shift+Right | Extend the cell selection by a column |
| Context Menu key, Shift+F10 | Open the selected cells' context menu |

These are spreadsheet shortcuts. CASSim suppresses their competing browser defaults while they
are in use.

On the spreadsheet, right-click a cell or row number for its CASSim context menu. Hold the
physical keyboard's Ctrl key while right-clicking to use the browser's menu instead. This is
different from the on-screen keypad's ctrl key; browser or system gestures may vary by platform.

## On the on-screen keypad

The keypad has the same keys as the handheld, with the second functions (the blue **ctrl** and orange **shift** layers) printed on them. Press **ctrl** or **shift** first, then the key; the shift key has an orange outline to match its labels. While a modifier is waiting for the next key, a dot appears beside its name.

- ctrl then **doc**: add a page
- shift then **doc**: add a Problem. The blue **+page** legend changes to orange **+problem**
  while shift is selected. Both shortcuts open a page-type picker.
- ctrl then **esc**: undo
- ctrl then **Z** or **Y**: undo or redo; ctrl then **C**, **X** or **V**: copy, cut or paste
- ctrl then **▲**: Page sorter; ctrl then **◀** or **▶**: previous or next page
- shift then **◀** or **▶**: select part of an entry; shift then **tab**: previous slot
- ctrl then **7** or **1**: first history row or back to the entry line; ctrl then **8** or **2**: start or end of the entry
- **var**: variables menu; ctrl then **var**: store arrow `→`; ctrl then **del**: clear the entry
- **templates**: template grid; ctrl then **templates**: `:=`
- In the **π**, **trig** or **templates** grid, press the same key again to move to the next
  item, wrapping back to the start; press **enter** to choose it.
- ctrl then the **divide** key: fraction; ctrl then the **square** key: square root; ctrl then **^**: nth root
- shift then **+** or **−**: integral or derivative template
- ctrl then **eˣ**: natural logarithm; ctrl then **10ˣ**: logarithm with a base
- ctrl then **(** or **)**: insert paired square or curly brackets
- ctrl then **×**: insert paired quotes; shift then **divide**: insert `\`
- ctrl then **(−)**: insert `Ans`; ctrl then **space**: insert `_`
- ctrl then **catalog**: symbols; ctrl then **=**: relations (<, ≤, ≠ and so on)
- ctrl then **shift**: Caps lock
- ctrl then **enter**: answer as a decimal
- ctrl then **menu**: context menu for the selected spreadsheet cell or cells (the blue menu-and-pointer icon)

The round key in the middle of the arrows works like a joystick. Press it and slide your finger away from the centre: a pointer appears on the screen and moves that way, faster the further you slide. It hides about a second after it stops, or when you press another key. Tap the key while the pointer shows to click where it points: a menu item, a line of the history (click it again to copy it to the entry line), the entry line, or a spreadsheet cell. With the pointer hidden, a tap chooses the highlighted item. The real handheld's touchpad works differently (the pointer moves only while your finger moves, and stays on the screen); CASSim's joystick is its own design.

The **flag** key, at the end of the h to n row, adds accents: type a letter, then press it to change the letter to è, then é, ê, ë and so on, and back to the plain letter. It works on the entry line and while typing in a spreadsheet cell. The small ⏎ key in the bottom corner, beside a wider space bar, is return, which is not the same as **enter**: enter (with a green ring) evaluates the entry line. The green rings on x, y and z just make the usual variables easy to find.

## Typing symbols

Use the on-screen keypad or the symbols menu for π, ∞, ⅇ, ⅈ, ° and similar. As on the handheld, ⅇ and ⅈ are different from the letters `e` and `i`, so `e` is an ordinary variable. The plain keyboard spellings are listed in [[Text interface]].
