# Settings

## Document Settings

Doc, Settings & Status, **Document Settings**. These apply to every Problem in the document and are saved with it.

| Setting | What it controls |
|---|---|
| Angle | Radian, Degree or Gradian |
| Calculation mode | Auto, Exact or Approximate |
| Real or complex | Real, Rectangular or Polar |
| Display digits | Float 1 to 12, or Fix 0 to 9 |
| Letter case | How letters are typed |
| Results as keyboard text | Show results with plain keyboard spellings |

On the handheld, VCE Methods usually uses Radian, Auto, Real; Specialist uses Radian, Auto, Rectangular; and General Mathematics usually uses Degree, Approximate, Real. Set the document up first, as you would on the handheld, because these settings change how answers look.

## Handheld Setup

Doc, Settings & Status, **Handheld Setup**. These belong to your device, not the document.

- **Start in:** Handheld or Computer
- **Maths size:** how large the maths is drawn
- **Zoom:** scales everything on screen
- **Keypad letters:** ABC or QWERTY
- **Appearance:** choose Dark, Light or High contrast. The choice is shared by Home and every
  CASSim app, and **CASSim ▸ Appearance…** opens the same dialog. You see a theme as soon as
  you choose it; **Save** keeps it and **Cancel** goes back. Open **Customise colours** to
  change single colours: tap a colour swatch to choose from the palette, or enter a six-digit `#RRGGBB` value.
  Edits are remembered separately for each preset on this device. **Reset preset** restores
  the selected preset's defaults; **Cancel** discards the edits made in that dialog.
  Custom colours can reduce contrast, so check that text and controls remain easy to see.
