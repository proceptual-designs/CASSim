# Getting started

## Open it

Open <https://cassim-app.pages.dev/> in a recent version of Chrome, Safari, Edge or Firefox. (The other CASSim sites are listed on the [[Home]] page.) The first visit downloads the whole app (about 90 MB) and can take a minute or more on a slow connection; a loading screen appears while the app starts. Later visits are much quicker.

## Install it (optional)

CASSim can be installed so it opens like an app and works with no internet.

- **Chrome, Edge or a Chromebook:** use the install button in the address bar, or the **Install** button in CASSim's toolbar when it appears.
- **Safari on iPhone or iPad:** Share, then **Add to Home Screen**.
- **Safari on a Mac:** File, then **Add to Dock**.

The first visit must be able to reach the site and finish downloading the offline cache. The loading
screen disappearing does not necessarily mean caching has finished, and there is not yet a cache
completion indicator. Before relying on it at school, open and install it on an unrestricted
network, leave it open to finish downloading, then turn the network off, reopen the installed app
and try a calculation. Use the same device and browser profile; clearing browser storage can remove
the offline copy. Updates need a connection to the site, but a cached copy can still run when an
update check fails.

## Your first calculation

1. Type an entry, for example `solve(x^2-2=0,x)`, using your keyboard or the on-screen keypad.
2. Press **Enter**. The answer appears above the entry line.
3. Press **Ctrl+Enter** to get the answer as a decimal.
4. Press the up arrow to reuse an earlier entry or answer.

Fractions, roots, powers and other templates appear as you would write them on paper. Use the arrow keys to move between the parts. The Templates menu has the full set.

## Where things are

- **Menu** (F2 on a computer, or the menu key): the calculation menus (Actions, Number, Algebra, Calculus, Probability, Statistics, and so on).
- **Doc** (F4, or the doc key): files, editing, view, pages and settings.
- Menus are numbered like the handheld. Press the number of an item to choose it.
