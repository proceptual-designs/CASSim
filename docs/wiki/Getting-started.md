# Getting started

## Open it

Open <https://cassim-app.pages.dev/> in a recent version of Chrome, Safari, Edge or Firefox. Each app also has its own site that opens straight into it; [[Which site to use]] lists them. The first visit downloads the whole app (about 90 MB) and can take a minute or more on a slow connection; a loading screen appears while the app starts. Later visits are much quicker.

CASSim opens to its Home screen, where you choose a calculator or other tool. To go straight to one, use or bookmark its link:

- Nspire calculator: <https://cassim-app.pages.dev/#/app/nspire>, or its own site <https://cassim-tin.pages.dev/>
- Pseudocode & Python: <https://cassim-app.pages.dev/#/app/pseudocode>, or <https://cassim-pseudo.pages.dev/>
- Scientific calculator: <https://cassim-app.pages.dev/#/app/scientific>, or <https://cassim-sci.pages.dev/>

**Home** in the CASSim menu takes you back to the choice of apps.

## Install it (optional)

Any CASSim site can be installed so it opens like an app and works with no internet. Each installed site gets its own icon (see [[Which site to use]]).

- **Chrome, Edge or a Chromebook:** use the install button in the address bar, or the **Install** button in CASSim's toolbar when it appears.
- **Safari on iPhone or iPad:** Share, then **Add to Home Screen**.
- **Safari on a Mac:** File, then **Add to Dock**.

The first visit must be able to reach the site and finish downloading the offline cache. The loading
screen disappearing does not necessarily mean caching has finished, and there is not yet a cache
completion indicator. Before relying on it at school, open and install it on an unrestricted
network, leave it open to finish downloading, then turn the network off, reopen the installed app
and try a calculation. Use the same device and browser profile; clearing browser storage can remove
the offline copy. Updates need a connection to the site, but a cached copy can still run when an
update check fails.

## Your first steps

- **Nspire:** type `solve(x^2-2=0,x)` and press Enter. More in [[Nspire calculator|Nspire]].
- **Pseudocode & Python:** choose a program from **Examples** and press **Run**. More in [[Pseudocode & Python|Pseudocode]].
- **Scientific:** type 2 ÷ 3 + 3 ÷ 4 and press =, or open **Tutorials** for a guided lesson. More in [[Scientific calculator]].
