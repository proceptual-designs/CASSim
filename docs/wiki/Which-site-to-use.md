# Which site to use

Every CASSim site runs the same apps; they differ in what opens first and in what they hold.

| Site | Opens to | Use it when |
|---|---|---|
| <https://cassim-app.pages.dev/> | The Home screen, with all three apps | You use more than one app, or want them all in one place |
| <https://cassim-tin.pages.dev/> | The Nspire app | You only need the Nspire simulator |
| <https://cassim-pseudo.pages.dev/> | The Pseudocode & Python app | A class only needs pseudocode and Python |
| <https://cassim-sci.pages.dev/> | The Scientific app | Younger students, or a class that only needs a scientific calculator |
| <https://cassim-calc.pages.dev/> | The Home screen, with the newest changes | You want to try something before it is released. It may break. |

A single-app site has no Home screen and no way to open the other apps, which keeps it simple for students. Its download is a little smaller than the all-in-one site's.

## The icons

Installed sites appear as separate apps, each with its own icon. All of them show **CAS** over a blue **SIM** bar; the mark after SIM tells them apart:

| Mark after SIM | Site |
|---|---|
| none | CASSim, all three apps |
| ℕ | CASSim Nspire |
| ‹ › | CASSim Pseudocode & Python |
| a flask | CASSim Scientific |
| β | CASSim testing |

The marks are the same symbols as on the Home screen.

## Saved work belongs to its site

Each site keeps its own saved documents, settings and tutorial progress. Work saved on the all-in-one site is not on the Scientific site, and the other way round. To move a document between sites, export it to a file or copy a share link (see [[Documents and sharing]] for the Nspire, and the Saving and sharing section of [[Scientific calculator]]). A share link opens on any site that has its app; a single-app site tells you which site opens a document for another app.

## Installing more than one

You can install several CASSim sites on the same device: each is a separate app with its own icon and its own offline copy. See [[Getting started]] for how to install.
