# Reporting a problem

If CASSim gives a different answer from the real calculator, behaves oddly, or is missing something you need, please say so. Every report helps.

## How to report

- **Students:** tell your teacher, or whoever gave you the CASSim link.
- **Anyone with a GitHub account:** open an issue at <https://github.com/simonjtyler/CASSim/issues>. Look through the open issues first, in case it is already there; if it is, add what you saw to that issue.

Issues are public. Do not put names, school details or assessment questions in them.

## Helpful details

- Which app: Nspire, Pseudocode & Python or Scientific (and, for Scientific, which calculator's keys)
- What you typed or pressed (copy the entry or the program) and what CASSim showed
- What the real calculator gives, if you know
- The settings: the Nspire's Document settings (angle, calculation mode, real or complex, digits), or the Scientific calculator's SETUP
- Which site you were using (see [[Home]]), and your device and browser
- The version, from **CASSim ▸ About**

A screenshot of CASSim helps. Please do not attach screenshots of the makers' own calculator software; describe what it shows instead.

## Security problems

If you find a security problem, do not open a public issue. Use **Report a vulnerability** on <https://github.com/simonjtyler/CASSim/security> so it can be fixed first.
