# 0011. The command line, and where M1 stands

Date: 2026-11-02. Status: accepted.
Code: `src/cassim/cli/`. Tests: `tests/unit/test_cli.py`.

## The `cassim` command (M1e)

- `cassim` starts a REPL; `cassim -c "ENTRY"` evaluates one entry; `cassim run FILE` (or `-` for standard input) runs a script, one entry per line. `--course general|methods|specialist` starts from a preset, `--set key=value` changes a setting, `--ascii` prints results in the plain keyboard spelling (`to_ascii`).
- A script skips blank lines and lines starting with `//`. It prints each entry and its result (`--quiet` prints only results), stops at the first error with exit status 1 (`--keep-going` carries on), and exits 2 for a bad option or unreadable file.
- In the REPL, `:set angle=degree calc=approximate`, `:settings`, `:vars`, `:new` (a new Problem), `:help` and `:quit` are the REPL's own commands. `:=` is still assignment.
- **Tab completion** offers every catalog function, every command, `Define`, the constants, the Problem's variables and functions, and, after `▶` or `@>`, the conversions. It is computed by `complete(session, line)`, a plain function, so it is tested without a terminal. The interactive prompt uses prompt_toolkit (a dev dependency and the `cli` extra) when there is a terminal and falls back to `input()` otherwise, so piped input and scripts need nothing extra.

## What M1 does not settle

- Every guess listed under "To check on the simulator" in decisions 0007 to 0010 still needs checking against the simulator; the corpus has only the captured cases, and all of them replay.
- Corpus cases are compared by value, so a wrong display form passes unless the case uses `compare: text`. The cases that do are the ones that fix the display.
