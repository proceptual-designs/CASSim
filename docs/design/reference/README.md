# TI-Nspire CX II-T CAS layout reference (design input)

Screenshots from the TI-Nspire CX CAS Premium Teacher Software, captured 2026-11-02 for the GUI design phase (after M1). Reference only: do not ship TI logos, artwork or keypad graphics (see AGENTS.md). CASSim needs its own branding and artwork.

| File | Shows |
|---|---|
| layout-keypad-sidescreen-dark.png | Keypad + SideScreen view, Dark keypad theme, Handheld document preview, 150% zoom. Calculator page with two results (`2/10 → 1/5`, shown as stacked fractions, left-aligned input, right-aligned result). |
| layout-handheld-only.png | "Handheld Only" window: the full handheld on its own (screen above the keypad). |
| layout-document-preview-computer.png | Document Preview set to "Computer" (full-width page, larger text) with the keypad beside it. |
| layout-keypad-outline-theme.png | Keypad theme menu (Dark / Light / Outline); Outline selected, with the Calculator page open. |

Things to note for the design: the keypad key layout and secondary labels (ctrl/shift), the page tab strip (`1.1`, document name, `RAD` indicator, battery, close), the shaded history rows with input left and result right, and the active entry line with a text cursor below.
