# Fonts

`NotoSansSymbols2-Regular.ttf`: Noto Sans Symbols 2, SIL Open Font License 1.1
(https://github.com/notofonts/noto-fonts). Used only for the arrow and triangle glyphs in
buttons and keys (`cassim.app.ui.SYMBOLS`), because the browser's fallback font is fetched from a
Google server and the offline build cannot reach it (FR-PWA-002).
